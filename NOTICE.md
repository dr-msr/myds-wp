# Notice

## What this project is

MYDS WP is an independent, community implementation of MYDS, the Malaysia Government Design System, for WordPress. It is based on the public repository at https://github.com/govtechmy/myds and the documentation at https://design.digital.gov.my.

It is not affiliated with or endorsed by the Government of Malaysia, and it is not a release of the MYDS team.

## Relationship to MYDS

No file from the MYDS repository is included in this theme. The design system is expressed again for WordPress:

- The names and values of the colour tokens are recorded in `tools/tokens.json`, and `theme.json` and `assets/css/tokens.css` are generated from that record.
- The type scale, spacing, radius, shadows, breakpoints and grid follow the published MYDS specification.
- The component styles in `assets/css/myds.css` were written for WordPress block markup, following the published behaviour of each MYDS component.
- The icons, including the flag in the masthead pattern, were drawn for this theme.

The MYDS values were read from the repository on 26 November 2026, at commit c7cac05.
