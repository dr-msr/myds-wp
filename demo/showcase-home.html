MYDS-WP

A WordPress block theme that implements MYDS, the Malaysia Government Design System: colours in light and dark, Poppins and Inter, the type scale, the 12-8-4 grid and the components. It needs no plugin.

Install

  1. Download myds-wp.zip from the latest release.
  2. In WordPress, go to Appearance, Themes, Add New Theme, then Upload Theme.
  3. Choose myds-wp.zip, select Install Now, then Activate.

Requires WordPress 7.1 or later.
